How to read these results

Each model scores the same canonical residues in the first 511 amino acids, or the entire sequence if shorter. Lower pseudoperplexity means that the model assigned higher probability to the observed residues.

The family preview uses eight selected sequence inputs per family. Repeated inputs can map to additional proteins. A full-family result requires verified scores for every protein in the frozen cohort.
