How to read these results

Each model scores the same canonical residues in the first 511 amino acids, or the entire sequence if shorter. Lower pseudoperplexity means that the model assigned higher probability to the observed residues. Each family here has 2,048 proteins.

The family preview uses eight selected sequence inputs per family; repeated inputs can map to additional proteins. Preview and production counts are separate. A full-family result is complete only when all 2,048 memberships have verified scores for that checkpoint.
